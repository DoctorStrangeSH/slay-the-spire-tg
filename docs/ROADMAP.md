# Slay And Spire — конечная дорожная карта релиза 1.0

> **Главный принцип:** проект больше не расширяется новыми игровыми системами до завершения релиза 1.0.  
> Полное обязательное ТЗ: [PROJECT_SPEC.md](PROJECT_SPEC.md).

## Зафиксированный объём

- [x] Три доступных героя: Берсерк, Инженер, Псайкер.
- [x] Три акта с процедурными картами по 16 этажей.
- [x] Связная генерация маршрутов с seed и контрольными этажами.
- [x] Боевое ядро, карты, энергия, статусы, намерения и конструкции Инженера.
- [x] Награды карт, улучшения и реестр реликвий.
- [x] Обычные/элитные бои, события, магазин, сокровищница и отдых.
- [x] Три босса актов.
- [x] Секретный босс Сборщик Последнего Долга с последствиями выбора у Безликого Торговца и тремя фазами.
- [x] Чекпоинты забега между комнатами и восстановление старых вариантов карты.
- [x] История забегов, достижения и косметические награды.
- [x] Дизайн-система «Тёмный собор», русскоязычный интерфейс и базовая мобильная адаптация.
- [x] Telegram Mini App и браузерная публикация на GitHub Pages.
- [x] CI: проверка синтаксиса и регрессионные тесты.

Отметки выше означают, что соответствующая система присутствует в текущем проекте. Они не отменяют проверки качества, перечисленные ниже.

## Что не делаем до релиза

- Не добавляем новые классы, акты, боссы, карты, реликвии и типы комнат.
- Не начинаем новую секретную концовку, цепочку печатей или дополнительные испытания.
- Не добавляем PvP, кооператив, облачные сохранения, серверный профиль и монетизацию.
- Не переписываем работающие системы без подтверждённого дефекта.
- Не запускаем новые художественные/контентные направления, если текущие ассеты выполняют требования.
- Не превращаем исправление одного дефекта в создание новой подсистемы.

Все идеи такого типа переносятся в отдельный backlog после 1.0.
